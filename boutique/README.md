# Boutique de modèles Excel / Google Sheets

Objectif : vendre des modèles de tableurs (Etsy) et ajouter un produit par semaine.
Chaque produit en ligne continue de se vendre, donc les ventes s'additionnent au fil des mois.

## Produits

| Produit | Dossier | État |
|---|---|---|
| Planificateur de budget 2027 | `budget/` | Fichier prêt, annonce à créer |

## Planificateur de budget

- `budget/Budget_2027.xlsx` : version vierge, **c'est le fichier qu'on vend**.
- `budget/Budget_2027_exemple.xlsx` : version remplie d'exemples, pour les photos de l'annonce.
- `budget/build_budget.py` : régénère les deux fichiers (`python3 build_budget.py 2028` pour une autre année).
